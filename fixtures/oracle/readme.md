# gfj-oracle

Throwaway fixture repo for [gh-forgejo-shim](https://github.com/dirtydishes/gh-forgejo-shim).

It has a twin on Forgejo (`git.dirtydishes.dev/dirtydishes/gfj-oracle`). A scenario script builds the
same pull requests, reviews, and CI states on both. Real `gh` output captured against this repo is the
oracle the shim's Forgejo output is tested against.

Everything here is disposable. Please don't open issues or PRs.
