## Discoveries And Decisions

- Routing had a second handwritten host/config parser. S3 removed it and now loads the same typed `HostRegistry` used by the configuration CLI.
- Provider identity is resolved before command support. A resolved Forgejo repository therefore stays inside the shim even for an unsupported command, while GitHub and unconfigured hosts still delegate.
- The read-only command context keeps the canonical repository for links and output, while a small HTTP adapter maps calls to the profile API transport.
- URL-form Git remotes dropped explicit ports before registry lookup. Repository parsing now preserves the full transport authority after user-info removal.
