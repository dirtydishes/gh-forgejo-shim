## Adaptations

- Add `crates/gh-forgejo-shim/src/read_only.rs` to the narrow S4 ownership surface. `auth.rs` can discover a token for a host, but the routed `HostProfile` owns the distinct `credential_host`; the native dispatcher must pass that field into discovery. This is the smallest file-scope change that can satisfy the accepted outcome. It does not change provider routing, repository identity, accepted behavior, dependencies, review roles, repair limit, CI gates, rollback, or the one-PR rule.
