## Discoveries And Decisions

- A fixture-only `PATH` can keep real Git available without exposing any other host executable by copying the Git binary resolved by the parent test runner into the fixture's private `bin`.
- GitHub's moving stable Rust toolchain can expose a branch-wide lint failure even when a phase's own source is correct. Keep that repair in a separate Beads issue when it falls outside the phase boundary.
