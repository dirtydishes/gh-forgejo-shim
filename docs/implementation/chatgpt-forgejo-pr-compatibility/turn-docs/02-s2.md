## Discoveries And Decisions

- A profile table is intentionally inert until its canonical host also appears in the legacy `hosts` list. This keeps the current binary and older installed binaries on the same routing boundary.
- `FJ_SHIM_HOSTS` remains a full replacement for file-backed host profiles. Values are normalized and deduplicated before the registry is built.
- Repeating `config add-host` for an existing canonical host is an additive update: omitted API-root and credential-host values stay unchanged, and new aliases join the stored set.
