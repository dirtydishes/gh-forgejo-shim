## Discoveries And Decisions

- Canonical transport identity belongs to `provider`, not `config`. `config` keeps compatibility re-exports while the registry validates and owns normalized transport keys.
- A Forgejo route now carries one `ForgejoTarget`. Its profile and canonical host cannot be absent or disagree, while its repository remains optional for host-only `auth` and `api` commands.
- Repository URLs are identity inputs only in the positional target slot of commands that accept them. URLs inside option payloads are ordinary data.
- Repository identity is now selected once by `CommandProviderTarget`; local handlers consume the routed repository and no longer reinterpret raw repository flags or positional targets.
